Генератор L3-конфигураций для Huawei S5731

Тот же движок, что используется в работе на объектах «Полюса»: разбирает «сырой» L3-файл генератора топологии, чинит секции и подставляет переменные (VLAN, RADIUS/TACACS+, AAA, SNMP, NTP) в проверенный шаблон 802.1X-профиля. Всё считается локально в браузере — ничего не уходит на сервер.

Стек
Python / Flask, JS-движок для демо
Оборудование
Huawei VRP · S5731-S24P4X
Задача
Снизить риск ошибки при массовой настройке
Huawei VRP · S5731-S24P4X
Cisco IOS (скоро)
Eltex (скоро)

2 Переменные
3 Конфиг

    Зачем это нужно
    
      
    Массовая настройка коммутаторов на распределённых промышленных площадках — источник человеческих ошибок: пропущенный VLAN, неверный uplink-порт, забытый ACL. Генератор берёт уже размеченный L3-файл (результат работы отдельного скрипта проектирования топологии), автоматически находит VLAN по именам, подставляет их в роли (Data/Voice/Printers/AP_Mgmt) и собирает итоговый конфиг по единому проверенному шаблону с 802.1X, RADIUS/TACACS+ и SNMP.
    
      
    Как это устроено
    
      
      
        
    • Парсер вычищает служебный мусор из «сырого» файла и группирует секции по маркерам
      • 
        
    • VLAN определяются по имени и автоматически связываются с нужными переменными шаблона
      • 
        
    • Мастер из 3 шагов: загрузка файла → проверка/правка переменных → готовый конфиг с предупреждениями
      • 
        
    • Проверки перед выдачей: не пропущена ли команда save, не остались ли незаполненные плейсхолдеры
