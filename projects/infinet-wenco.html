Полюс Золото · карьер Еруда

Сеть связи Infinet для карьерной техники и диспетчеризация Wenco

Участие в построении радиосети для подвижной горной техники — на момент реализации крупнейшее внедрение Infinet на подвижных объектах. Сеть стала транспортом для системы автоматической диспетчеризации Wenco.

Роль
Специалист связи
Объект
Карьер Еруда, Полюс Золото
Технологии
Infinet Wireless, Wenco FMS
Масштаб
Крупнейший проект Infinet на подвижной технике

Задача

Автоматическая диспетчеризация горных работ требует непрерывного канала до каждой единицы техники: самосвалов, экскаваторов, буровых станков. Система Wenco собирает телеметрию и выдаёт задания в реальном времени — при разрыве связи диспетчер теряет управление парком, а техника простаивает.

Сложность в том, что карьер — худшая среда для радиосвязи. Уступы экранируют сигнал, техника непрерывно перемещается между горизонтами и меняет положение относительно базовых станций, а сама геометрия чаши меняется по мере отработки. Обычные точки доступа здесь не дают ни зоны покрытия, ни устойчивого роуминга.

Решение

  • Радиосеть на оборудовании Infinet Wireless — с расчётом покрытия под геометрию карьера и режимом работы с подвижными абонентами
  • Абонентские терминалы на единицах горной техники: самосвалы, экскаваторы, вспомогательный парк
  • Базовые станции по бортам карьера с перекрытием зон — чтобы техника не теряла канал при переходе между горизонтами
  • Транспорт до диспетчерской и интеграция с существующей инфраструктурой связи предприятия (ВОЛС, ядро сети)
  • Стыковка радиосети с системой Wenco — передача телеметрии и диспетчерских заданий в реальном времени

Особенность проекта

По масштабу применения Infinet на подвижных объектах проект стал крупнейшим из реализованных на этом оборудовании. Основная инженерная сложность — не в отдельных линках, а в обеспечении бесшовного перехода техники между секторами покрытия при постоянно меняющемся рельефе карьера.

Результат

Сеть обеспечила работу автоматической диспетчеризации карьерной техники: диспетчер получил онлайн-картину положения и состояния парка, а система — канал для выдачи заданий на технику без участия оператора связи.
